# KEYLINE 打字学英语

从工作台进入「打字记词」，或运行 `pnpm dev:typing` 直接预览。运行 `pnpm app` 检查 Tauri 桌面版。

## 体验

- 游戏大厅、指法关卡、单词训练、文章挑战、训练档案共用独立全屏布局；进入时隐藏套件标签栏与侧栏。
- 深色键盘港口场景、琥珀色提示、贴边 HUD；SVG 场景不依赖外部图片、字体或网络。
- 专注、地鼠、射击、堆塔共用打字引擎；实时显示 WPM、正确率、连续命中、进度。
- 首次有效敲击后开始计时。Esc 暂停/恢复；切换到其他窗口或隐藏页面会自动暂停。声音设置打开期间也暂停。
- 青轴、奶油轴、静音红轴、打字机、街机五种音色，可调音量、试听与静音。Web Audio 本地生成短样本并复用；发音使用系统语音。
- 音色、音量、静音、学习记录与课程进度保存在原有 SQLite 数据库。旧数据库自动采用奶油轴、55% 音量，不改变旧静音状态。
- 保存失败提供重试，重试不重复记入训练；IndexedDB 等待事务提交才报告保存成功。

## 全屏行为

Tauri 使用窗口原生全屏接口，退出模块时只恢复由该模块开启的全屏。浏览器从工作台点击进入时请求 Fullscreen API；直接加载页面或浏览器不支持该 API 时保持满视口，右上角可再次请求全屏。Esc 的系统全屏退出行为由平台决定。

## 验证

```sh
pnpm test:typing
pnpm build
```

自动化测试覆盖原有打字规则、课程顺序、错键复习，以及暂停后的速度/时间、末题结算幂等性、设置迁移与边界值、五种音色的样本有效性与缓存复用。

界面验收：

1. 从工作台进入，确认工具栏/侧栏隐藏；退出后恢复工作台。
2. 完成一节指法课，包含错键与空格；确认正确率、评级、下一节、刷新后进度。
3. 单词跟打、默写、听写及文章练习；朗读、收藏、已掌握保持可用。
4. 切换四种玩法；打开设置、Esc、切换窗口后恢复，确认内容不跳题、暂停不计时。
5. 切换音色和音量，刷新后检查保留；静音/零音量不播放按键声。
6. 桌面、窄屏、矮窗口检查内容可滚动且控制可达；系统减少动态效果偏好下关闭界面动画。

浏览器已实测大厅、完整指法通关、完整文章挑战、单词默写、四种玩法、暂停/结算、60 秒热身精确结算、设置持久化和 1440×900、1280×800、390×844 布局。Tauri 原生全屏切换及 Windows 运行需在对应桌面应用中验收。
