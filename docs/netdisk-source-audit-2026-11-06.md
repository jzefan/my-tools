# 网盘搜索来源分析与修复记录

日期：2026-11-06。复现关键词：`史记`。

## 结论

不再依赖公开 PanSou 演示服务作为唯一默认入口。继续使用其开源插件提供的协议资料，但由工具箱自己直接查询两个已实测的来源：Melost 和 QKPAN。没有引入第三方服务端代码、部署数据库或增加 Docker 依赖。

## 同轮真实网络探测

先按源码协议测试，再检查返回的 JSON、标题和实际分享链接，不将 HTTP 200 或服务端总条数当成“已取得资源”。

| 候选来源 | 本机探测结果 | 决策 |
| --- | --- | --- |
| Melost `/v1/search/disk` | “史记”约 2.2 秒返回 50 条；百度过滤另返回 28 条，阿里过滤另返回 6 条。 | 默认启用；综合、百度、阿里分阶段合并。 |
| QKPAN `/v1/search/disk` | “史记”约 2.5 秒返回 50 条夸克结果，标题包含“史记研究集成”等匹配内容。 | 默认启用。 |
| PanSou 公开地址 | `res=all` 在 12 秒内收到 HTTP 200 和约 1.1 MiB 正文但未传完；另一轮 `res=merge` 16 秒无响应。 | 关闭默认；保留可选、自建支持。请求改为较小的 merge 响应。 |
| 混合盘旧 `/open/search/disk` | JSON 返回参数错误；`/v1/search/disk` 返回非 JSON 页面。 | 不将旧插件常量直接当成可用接口。 |
| 盘 666 | HTTP 403 页面。 | 未加入默认来源。 |
| 极客盘、迷搜搜 | 当前环境 TLS 连接失败。 | 未加入默认来源。 |
| 爱盘影视 | “史记”接口有效但返回空 movies 列表，范围偏影视；未进一步验证详情。 | 不作为书籍查询的默认替代。 |

这些是该日期、该网络的实测，不保证第三方服务永久在线。失败的源不会清空已从其他源取得的结果。

## 防止同类故障

1. 默认并发查询两个来源，各源单独超时、单独报错。
2. 旧配置自动升级到版本 2，避免仅改默认常量而让已安装客户端继续使用旧单源。
3. Melost 的综合页大多是夸克资源，因此补充百度和阿里查询。对上游 `size` 使用验证过的 50，避免不受支持的 100 被静默降为 10。
4. 测试覆盖直接协议解析、提取码、网盘类型、补充查询、旧配置迁移、自定义源保留，以及保存后的移除操作。
5. Rust 客户端实测“史记”和“红楼梦”；浏览器实测“史记”得到 115 个去重分享，首批约 1.8 秒、完成约 4.4 秒，未调用 PanSou。

首次版本曾通过“Linux”等关键词的 PanSou 联网测试，但不能由此推断公开服务在其他查询和时段稳定。现在以用户失败关键词的端到端结果作为验收依据。

本次完整验证：24 项前端测试、34 项 Rust 回归测试、1 项独立来源的真实联网测试通过。发布构建和 macOS app 打包通过，修复版应用位于 `src-tauri/target/release/bundle/macos/Workspace.app`。
