# 论文研读模块比对与补齐（2026-11-07）

比对对象：本项目 `src/components/paper/`、`src/services/paperApi.ts`、`src/utils/paperAi.ts`、`src/utils/citations.ts`、`src-tauri/src/paper_service.rs`，以及 `~/work/proj/reader` 的 renderer、core、ai、citations、shared 和 main 实现。

## 结论

修改前不一致。本项目具备类似的入口，但部分功能只有界面或单次会话实现，导入身份、持久化、Word 批注、AI 请求生命周期等行为也有差异。本次已经补齐下面列出的功能，并保留本项目原有的手稿编辑、润色、PDF 页面编辑和阅读状态管理。

功能对齐不代表源码或数据文件兼容。reader 使用 Electron、SQLite、utility process 和 RPC；本项目继续使用 Tauri、Rust 命令及 JSON 资料库，不直接读取 reader 的数据库，也不替换本项目其他工具模块。

## 差异与处理

| 范围 | 修改前 | 本次处理 |
| --- | --- | --- |
| 批量导入 | 仅单文件选择 | 多文件选择、Tauri 原生拖放、串行批次队列 |
| 文件去重 | 按路径替换并生成新 ID，笔记可能与新记录脱离 | 按 SHA-256 去重，保留已有 ID、批注、导读和草稿；同路径内容变化视为新文件 |
| 文件管理 | 引用原始路径，移动源文件后无法阅读 | 资料库托管副本；旧记录打开时迁移；保留原路径 |
| 原文完整性 | 外部修改原文件后继续使用旧批注 | 打开托管文档前校验内容哈希，改变后要求重新导入 |
| 导入解析 | 仅打开阅读器时解析 | 导入时解析并记录任务、参考文献和位置数量 |
| 切换论文 | 较慢的旧请求可能覆盖新论文数据 | 加载请求序号校验；按论文隔离文本、批注、问答与结果 |
| 保存流程 | React 更新回调内发起写入、失败仅日志 | 串行持久化、可读取的本地备份、错误提示与重试 |
| 损坏恢复 | 文件损坏后可能进入空库 | 原子替换、文件同步、Unix 目录同步、上次有效备份；无法恢复时显示错误并阻止覆盖 |
| 密钥 | localStorage 和资料库中存明文 | macOS Keychain / Windows Credential Manager；不可用时仅会话保存；配置和资料库备份不包含密钥 |
| 多服务商 | 切换服务商后复用旧密钥 | 按服务商保存配置、分别读取系统凭据，保持本项目更多兼容服务商 |
| PDF 文本 | 所有片段以空格拼接，丢失参考文献换行 | 保留 `hasEOL` 换行，修复目录与参考文献识别 |
| PDF 目录 | 仅启发式识别标题 | 优先读取原生书签、命名目标和层级；损坏目标不影响其余条目；无书签时回退标题 |
| 全文搜索 | 缺失 | 正文搜索、最多 100 条结果、页/段跳转；PDF 中定位引文；支持 Cmd/Ctrl+F |
| 连续阅读 | 全量画布，旋转时重新加载文件 | 可见页附近按需渲染；文档、测量和渲染生命周期分离；销毁与取消过期任务 |
| 阅读位置 | 不保存旋转，初始滚动恢复不完整 | 保存页/段、缩放、模式、旋转；连续模式恢复；位置边界校验 |
| PDF 选区 | 单个外接矩形，旋转与跨页不完整 | 多行与连续跨页选区，分段保存；旋转零度标准坐标与当前视图互相投影 |
| 区域选择 | 截图与位置未进入完整问答链 | 截图、所在页与矩形进入问答输入及结果保存；支持区域证据 |
| Word 阅读 | 对简化合法 DOCX 报错 | 现有排版渲染器失败时回退 OOXML 结构渲染；保留常见表格合并、列宽、底色、对齐与内嵌图片 |
| Word 定位 | 按临时分页定位 | 按正文段落/表格序号定位，区分“页”和“段” |
| Word 批注 | 忽略传入批注；DOM 临时 mark 重开消失 | 根据存储文本与分段重建高亮，重挂载后恢复；支持跨段选区 |
| 引用匹配 | 重复编号被覆盖并当作高置信度 | 保留重复候选并标示歧义；正确结束附录前的文献列表 |
| 引用导航 | 仅点击正文后显示单条 | 可浏览完整参考文献；资料库可展开引文；精确匹配库内论文；可编辑搜索词 |
| 外部链接 | 任意 URL | 与 reader 相同的学术站点白名单、DOI/arXiv 标准化；支持 PDF 内嵌链接 |
| AI 上下文 | 截断开头，选区误作为问题 | 区分问题、选区、附近正文、截图；发送范围可预览和关闭；长文导读均匀取样以包含后段 |
| AI 估算 | 缺失 | 显示 token 及已知模型的历史配置价格估算；价格日期明确标注为 2026-10-08，非实时价格 |
| AI 响应 | 非流式、不能停止、错误变成可保存答案 | SSE 增量与思考过程、停止、超时、失败重试；错误独立展示 |
| 问答证据 | 仅纯文本回答 | 验证所有正文/选区/区域引用；无引用或错误引用保存为草稿；证据可跳转 |
| 导读证据 | 每维单段、可无证据冒充作者陈述 | 每维多个论点；区分作者陈述/模型归纳/评论；核验引文；排除无证据作者陈述 |
| 后台生成 | 切换侧栏或论文丢失状态 | 问答会话与任务状态独立于阅读器挂载，流式请求可继续；导读保存按论文 ID 合并 |
| 批注操作 | 缺少复制、撤销；AI 字段保存不完整 | 复制、删除撤销、问答字段和证据保存；编辑回答后标为草稿 |
| 导出 | 硬编码 `/tmp`，仅提示“已复制” | 原生保存对话框；导出导读与批注 Markdown；保留论点归属与证据 |
| 系统操作 | 阅读器无系统打开与打印入口 | 系统打开；独立打印文档；资料库目录和不含密钥的诊断导出 |
| 任务 | 缺失 | 导入、解析、导读、问答历史；停止、重试、回到论文；重启后运行中任务标为中断 |
| 原有编辑器 | 未接入识别出的参考文献 | 将解析结果传入手稿编辑器；修复截图插入草稿 |

## 实现入口

- `src/components/paper/PaperView.tsx`：导入、异步文档切换、资料库与编辑器衔接。
- `src/components/paper/PdfCanvasViewer.tsx`：按需渲染、选区、标准坐标、书签及链接。
- `src/components/paper/DocxCanvasViewer.tsx` / `src/utils/paperDocx.ts`：Word 段落定位、持久批注及结构回退。
- `src/services/paperApi.ts` / `src-tauri/src/paper_service.rs`：托管文件、哈希校验、备份、凭据和导出。
- `src/services/paperJobs.ts` / `src/services/paperChats.ts`：跨组件生命周期的任务与问答。
- `src/utils/paperAi.ts`：流式请求、取消、上下文控制、导读和问答证据核验。
- `src/utils/citations.ts` / `paperOutline.ts` / `paperGeometry.ts`：移植并适配 reader 的纯函数规则。

## 验证

1. TypeScript 全量类型检查。
2. 论文版 Vite 生产构建。保留现有大 chunk 提示，不为此修改其他工具的打包结构。
3. `npm run test:paper`：AI 错误与引文校验、全文搜索、引用歧义、原生目录、旋转坐标、长文取样、SSE 分片、上下文关闭、存储串行化、备份恢复、密钥脱敏及 PDF 离线资源。
4. `cargo test --offline --manifest-path src-tauri/Cargo.toml --lib paper_service::tests`：托管副本与去重、内容篡改检测、原子保存与损坏恢复、无效写入拒绝、Markdown 导出。
5. Electron 实际浏览器回归：真实 PDF 解析与书签、搜索、流式问答、问答过程中重挂载阅读器、证据保存、批注删除撤销；真实 Word 合并表格及重挂载后的高亮恢复；1440 与 1024 宽度截图检查。

界面测试启动方式：先启动论文版 Vite；安装了 Electron 时运行 `npm run test:paper-ui`，或通过 `PAPER_TEST_ELECTRON` 指定已有 Electron 可执行文件。测试夹具从参照项目复制，未修改参照项目。

## 消融检查及验证边界

已进行消融检查：去掉旧 Word 临时 DOM 高亮、旧 PDF 全量画布路径、伪缩略图占位块和重复的 Markdown 拼接。保留 Word 排版渲染与结构回退，是为同时支持常规完整文档和缺少可选部件的合法文档。新增操作复用现有侧栏与紧凑工具栏，并检查窄窗口换行。

本次未使用真实 API 密钥发送论文，AI 网络行为使用分片 SSE 与失败模拟验证；系统凭据接口已经接入，但未对用户钥匙串写入测试密钥。Windows 凭据、原生对话框与打印机尚未在 Windows 实机验收。HTML 打印路径是本项目的实现，和 reader 的 Electron PDF 打印窗口不是同一条代码路径。

仍保留的平台实现差异：本项目没有移植 Electron utility process 的崩溃重连协议、SQLite WAL 恢复协议、Electron 菜单/打印窗口和独立应用注册配置。这些属于宿主实现，不能据本次功能测试宣称两个应用的故障恢复、打印质量或所有复杂 DOCX 样式完全等价；对应平台与大型真实论文语料仍需后续验收。
